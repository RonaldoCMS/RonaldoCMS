01 · chi sono

Tradurre problemi reali in software chiaro e manutenibile.

Sono Fabio Danubbio, Full Stack Developer con base a Nola, in provincia di Napoli. Lavoro su tutta l'architettura di un'applicazione: dal modello dei dati alla sicurezza, dalle API fino all'interfaccia che le persone usano davvero.

Negli ultimi anni ho costruito app mobile per agenti di vendita collegate a gestionali ERP, un layer di sicurezza per il portale italia.it e app di domotica che dialogano con l'hardware via WiFi e Bluetooth. Mi piacciono i progetti in cui la tecnologia deve semplificare il lavoro di qualcuno.

Fuori dal codice: palestra, chitarra (sto imparando), cinema, teatro e almeno un viaggio al mese verso un posto nuovo.

  • 2021 → oggisviluppo professionale
  • Nola (NA)Italia, anche da remoto
  • IT · ENlingue di lavoro

Frontend & Mobile

App cross-platform in Flutter e interfacce web con React e Next.js, con gestione dello stato e design pattern solidi.

Backend & API

API scalabili con Node.js ed Express e soluzioni enterprise con Java Spring Boot: architetture robuste e manutenibili.

Database & Sicurezza

MongoDB, PostgreSQL, MySQL e MSSQL con query ottimizzate, autenticazione JWT/OAuth2 e comunicazione in tempo reale via WebSocket.

Cloud & DevOps

Firebase, Docker e pipeline CI/CD, con workflow Git e metodologie Agile per deploy automatizzati e monitorati.
